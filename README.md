# Portfolio INF2501 — Bùi Ngọc Thảo

Website tĩnh gồm trang Giới thiệu, Dự án, sáu trang bài tập và Tổng kết.

## Cấu trúc
- `index.html`: Giới thiệu
- `projects.html`: Danh mục sáu bài tập
- `project-1.html` đến `project-6.html`: Trang riêng cho từng bài tập
- `summary.html`: Tổng kết
- `style.css`: Giao diện responsive
- `script.js`: Menu trên màn hình nhỏ
- `assets/portrait-placeholder.svg`: Ảnh minh họa vị trí ảnh chân dung

## Việc cần hoàn thiện trước khi nộp
1. Thay `assets/portrait-placeholder.svg` bằng ảnh chân dung của bạn (có thể đổi tên ảnh thành `portrait.jpg`, sau đó sửa đường dẫn trong `index.html`).
2. Bổ sung nội dung thật, ảnh chụp màn hình và sản phẩm thực tế cho từng trang bài tập. Các trang hiện chỉ có khung; không phải nội dung bài làm hoàn chỉnh.
3. Thêm các liên kết âm nhạc thật vào khu vực Góc âm nhạc trong `index.html`.
4. Với tệp Google Drive/OneDrive, bật quyền chia sẻ phù hợp để người có liên kết có thể xem.
5. Kiểm tra lại thông tin cá nhân và mọi liên kết trước khi công khai.

## Xuất bản bằng GitHub Pages
1. Đăng nhập GitHub và tạo repository mới, ví dụ `portfolio-inf2501`.
2. Giải nén ZIP này trên máy tính.
3. Tải toàn bộ **các tệp bên trong thư mục** lên repository (đảm bảo `index.html` nằm ở thư mục gốc).
4. Mở repository → **Settings** → **Pages**.
5. Trong phần Build and deployment, chọn **Deploy from a branch**.
6. Chọn branch `main`, folder `/ (root)`, rồi bấm **Save**.
7. Chờ GitHub Pages xuất bản và mở URL được hiển thị trong phần Pages.
8. Mở URL bằng cửa sổ ẩn danh để kiểm tra không cần đăng nhập; thử mọi menu và liên kết.

Nếu tài khoản hoặc giao diện GitHub hiển thị khác, hãy gửi ảnh màn hình để được hướng dẫn đúng bước.
